### 헤더파일
```c++
#include <헤더파일>
```
- **iostream**: C++의 표준 입출력 관련 라이브러리 
  - `std::cout`
  - `std::endl`
- C++의 라이브러리는 C와 다르게 `.h`가 붙지 않음

#### 이름 공간 (namespace)
> 각 헤더 파일(라이브러리) 내부의 함수, 객체 등을 구분하기 위해 사용함
- 예) `std::cout`: `std`부분은 입출력 라이브러리인 iostream 소속임을 알림


 ```c++
    namespace [헤더파일] { [내용] }
    using namespace [헤더파일]
  ```
- 이름 공간을 명시하지 않고 **자유롭게 선언 및 호출**하게 하는 기능
  - **`namespace [헤더퍄일]`**: 범위 내에서 자유롭게
  - **`using namespace [헤더파일]`**: 해당 스코프 내에서 전역적으로 자유롭게
> **주의사항**
> - **`using namespace std;`는 사용하지 않은 것을 권장**
>  - -->`std`에 이름이 겹치는 함수를 만들게 된다면, 오류가 발생하기 때문
