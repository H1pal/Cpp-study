## 문제

정수 `N`과 그 다음 `N`개의 정수가 주어질 때, 중앙값(median)을 구합니다.

중앙값이란, 주어진 값을 크기순으로 정렬했을 때 가운데에 위치하는 값입니다.

### 제한 사항

- N은 홀수입니다.
- 1 ≤ N ≤ 100
- -1,000 ≤ 각 정수 ≤ 1,000

### 입출력

- 입력
  - `N`: {**int**} 정수의 개수 (홀수)
  - `numbers`: {**int[]**} N개의 정수

- 출력
  - return: {**int**} 중앙값

### 입출력 예

| N | numbers | return |
|:--|:--------|:-------|
| 3 | [1, 3, 2] | 2 |
| 5 | [1, 2, 3, 4, 5] | 3 |
